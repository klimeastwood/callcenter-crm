# CRYPTOISK CRM & Trading Platform

**Разработчик:** KLIMIATA  
**Назначение:** Учебный симулятор для Института Следственного комитета (ИСК)  

---

## 📖 О проекте

**CRYPTOISK** — это комплексный образовательный проект, состоящий из двух связанных приложений:
1.  **CRM-система** для управления клиентской базой (колл-центр).
2.  **Трейдинговая платформа** (личный кабинет клиента) с имитацией криптовалютной биржи.

Проект создан для **обучения следователей** методам выявления и документирования мошеннических схем в сфере криптотрейдинга. Все данные (балансы, транзакции, карты) являются **вымышленными** и не используются для реальных финансовых операций.

---

## 🏗️ Основа проекта

За основу взята открытая CRM-система **Krayin CRM** (разработка Webkul), распространяемая под лицензией MIT.

**Что было доделано и изменено:**
*   **Полная русификация:** Переведены интерфейс, меню, формы, история изменений и системные поля.
*   **Брендинг:** Заменены логотипы, название и футер на CRYPTOISK / KLIMIATA.
*   **Кастомные модули:** Добавлены разделы «Криптовалюты», «История звонков», «Заявки на пополнение» и «Заявки на вывод».
*   **Роли и безопасность:** Созданы роли «Оператор» и «Модератор» с разграничением прав доступа (Data Scope).
*   **Интеграция с трейдингом:** Настроен обмен событиями (депозиты, ставки, выводы) между CRM и торговой платформой через общую базу данных.
*   **Учебный функционал:** Реализован механизм имитации пополнения/вывода средств с сохранением введенных данных карт (CVV, номер) для последующего анализа следователем.

## 🚀 Установка и запуск

### Требования
*   PHP >= 8.3
*   Composer
*   MySQL
*   Node.js & NPM

### Шаги установки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/klimeastwood/callcenter-crm.git
    cd callcenter-crm
    ```

2.  **Установите зависимости PHP:**
    ```bash
    composer install
    ```

3.  **Настройте окружение:**
    *   Скопируйте `.env.example` в `.env`.
    *   Настройте подключение к базе данных (`DB_*`).
    *   Сгенерируйте ключ: `php artisan key:generate`.

4.  **Выполните миграции:**
    ```bash
    php artisan migrate
    ```

5.  **Запустите сервер:**
    ```bash
    php artisan serve
    ```

6.  **Доступ к админ-панели:**
    *   URL: `http://127.0.0.1:8000/admin`
    *   Логин/Пароль: создаются при первой установке (или через сидер).
